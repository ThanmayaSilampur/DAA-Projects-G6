Algorithm: Job Sequencing with Deadlines

Input:
    A set of jobs, where each job has:
    - Job ID
    - Deadline
    - Profit

Output:
    Job sequence with maximum profit

1. Start

2. Read the number of jobs.

3. Read the ID, deadline, and profit of each job.

4. Find the maximum deadline among all jobs.

5. Sort all jobs in decreasing order of profit.

6. Create empty time slots from 1 to the maximum deadline.

7. For each job in the sorted order:
       a. Start checking from the job's deadline.
       b. Move backwards through the available slots.
       c. If an empty slot is found:
              Schedule the job in that slot.
              Add the job's profit to the total profit.
              Stop checking slots for this job.
       d. If no empty slot is available:
              Skip the job.

8. Display the scheduled jobs.

9. Display the maximum total profit.

10. Stop
